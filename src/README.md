
# PulseLink 🩸

### Smart Emergency Blood Donor & Availability Network

PulseLink is a frontend demonstration project designed to connect people searching for blood donors with a sample donor network.

## Features

- Dashboard with donor and request statistics
- Search and filter blood donors
- Demo donor registration
- Emergency blood request creation
- Request status tracking
- Pulse AI chatbot interface

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Lucide React
- Vite

## Installation

1. Clone this repository.
2. Open the project folder.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

## Project Status

Frontend prototype completed. Data is currently stored in React state and resets when the page is refreshed. No backend or real notification service is connected.

## Important Disclaimer

PulseLink uses fictional demonstration data. It does not verify donor eligibility, blood compatibility, blood availability, or coordinate real medical requests. Real emergencies must be handled through hospitals and qualified medical professionals.
